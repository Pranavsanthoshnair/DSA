# Data Structures and Algorithms in C

This repository contains implementations of core Data Structures and Algorithms using the C programming language.  
The codes are organized into two branches:
- **lab** branch: Programs implemented as part of official laboratory sessions.
- **practice** branch: Programs written during self-practice for better understanding and mastery.

---

## 📚 Lab Experiment List

1. Find the sum of two polynomials using arrays.  
2. Find the sum of two sparse matrices and transpose the resultant matrix.  
3. Convert infix expression to postfix (or prefix) and evaluate using a stack.  
4. Implement Queue, DEQUEUE, and Circular Queue using arrays.  
5. Implement Circular Queue using arrays.  
6. Implement backward and forward navigation of visited web pages in a browser using doubly linked list operations.  
7. Implement addition of polynomials using singly linked lists.  
8. Create a binary tree for a given arithmetic expression and find the prefix/postfix equivalent.  
9. Implement Binary Search Trees with insertion, search, and deletion using linked lists.  
10. Implement Breadth First Search (BFS) using arrays.  
11. Implement an efficient algorithm to search for a specific item in a sorted array and analyze time and space complexities.  
12. Implement Bubble Sort, Insertion Sort, Quick Sort, and Merge Sort, and compare the number of steps involved.  
13. Simulate a basic memory allocator and garbage collector using a doubly linked list.  
14. Insert a set of integers into a hash table with 10 slots using a hash (modulo) function.
